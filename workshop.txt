version=1
title=Action Speed Multiplier
description=[h1]Action Speed Multiplier[/h1]
description=Faster actions and much faster item transfers, in single player and on servers. Two sandbox options divide the vanilla time: actions and item transfers 20 times as fast by default.
description=
description=[h2]Why another speed mod[/h2]
description=In multiplayer the server decides how long every item transfer takes and the client just waits for it, so Lua-only speed mods cannot change transfer time there. They can only send several items in one request, which does nothing for a single item or for the floor. This mod patches the server's own transfer timing (Java, through ZombieBuddy), so every transfer is faster: one item, many items, bags, containers, vehicles and the floor.
description=
description=[h2]Sandbox options[/h2]
description=[list]
description=[*][b]Action speed[/b], 0.1 to 100, default 20: crafting, building, eating, reading, repairing, farming, animals and every other timed action except moving items.
description=[*][b]Item transfer speed[/b], 0.1 to 100, default 20: moving items between containers, bags, vehicles and the floor, and picking items up from the ground.
description=[/list]
description=The time is the vanilla time divided by the option: 2 is twice as fast, 1 is vanilla, 0.5 is twice as slow. Traits, moodles, wounded hands, gloves, weight and bag fullness still count as in vanilla, before the division. Set them when you start a new game, or in the server's sandbox settings.
description=
description=[h2]Requirements[/h2]
description=[list]
description=[*][b]ZombieBuddy[/b] (Java mod loader), enabled in the mod list
description=[*]Steam launch option [b]-agentlib:zbNative --[/b] (Project Zomboid → Properties → Launch options). Without it the mod does not load.
description=[/list]
description=On the first start ZombieBuddy asks once to approve ActionSpeedMultiplier.jar.
description=
description=[h2]Compatibility[/h2]
description=Build 42. Tested in single player. Multiplayer is not tested: the server needs ZombieBuddy (its Java agent) and this mod, and every client needs them too.
description=Replaces Faster Actions (marked incompatible): both divide action times, so together they would multiply. Timed actions from other mods are sped up too when they use the normal vanilla timing.
description=Can be added to or removed from an existing save; an existing save starts at the defaults.
description=
description=[h2]한국어[/h2]
description=행동 시간과 아이템 이동 시간을 샌드박스 옵션 두 개로 나눕니다. 기본값은 행동과 아이템 이동 모두 20배 빠르게입니다(각각 0.1~100, 1은 바닐라).
description=[b]행동 속도[/b]: 제작, 건설, 먹기, 독서, 수리, 농사, 동물 등 아이템 이동을 뺀 모든 행동. [b]아이템 이동 속도[/b]: 컨테이너, 가방, 차량, 바닥 사이 이동과 바닥에서 줍기.
description=멀티에서는 서버가 아이템 이동 시간을 정하고 클라이언트는 기다리기만 해서 Lua 모드로는 바꿀 수 없습니다. 이 모드는 서버의 이동 시간 계산 자체를 Java로 고쳐서(ZombieBuddy) 한 개, 여러 개, 바닥까지 모두 빨라집니다.
description=특성, 무들, 손 부상, 장갑, 무게, 가방이 찬 정도는 바닐라대로 계산한 뒤 나눕니다.
description=필요한 것: [b]ZombieBuddy[/b] 모드, 스팀 실행 옵션 [b]-agentlib:zbNative --[/b] (속성 → 실행 옵션). 싱글에서 테스트했고 멀티는 테스트하지 않았습니다. 멀티에서는 서버(ZombieBuddy Java 에이전트 포함)와 모든 클라이언트에 ZombieBuddy와 이 모드가 필요합니다. Faster Actions를 대체하는 모드라 같이 쓸 수 없게 표시했습니다.
