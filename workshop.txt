title=Transfer Speed Multiplier
description=[h1]Transfer Speed Multiplier[/h1]
description=Move items between containers faster, in single player and on servers. Putting items in and taking them out takes the vanilla time divided by a sandbox option: 20 times as fast by default.
description=
description=[h2]Why another speed mod[/h2]
description=In multiplayer the server decides how long every item transfer takes and the client just waits for it, so Lua mods cannot change transfer time there. They can only send several items in one request, which does nothing for a single item or for the floor. This mod patches the server's own timing (Java, through ZombieBuddy), so every transfer is faster: one item, many items, bags, containers, vehicles and the floor.
description=
description=[h2]Sandbox option[/h2]
description=[b]Item transfer speed[/b], from 0.1 to 100. The time is the vanilla time divided by it: 20 (default) is twenty times as fast, 1 is vanilla, 0.5 is twice as slow. Set it when you start a new game, or in the server's sandbox settings.
description=Weight, bag fullness, Dextrous / All Thumbs and gloves still count as in vanilla, before the division.
description=
description=[h2]Requirements[/h2]
description=[list]
description=[*][b]ZombieBuddy[/b] (Java mod loader), enabled in the mod list
description=[*]Steam launch option [b]-agentlib:zbNative --[/b] (Project Zomboid → Properties → Launch options). Without it the mod does not load.
description=[/list]
description=On the first start ZombieBuddy asks once to approve TransferSpeedMultiplier.jar.
description=
description=[h2]Compatibility[/h2]
description=Build 42. Tested in single player. Multiplayer is not tested: the server needs ZombieBuddy (its Java agent) and this mod, and every client needs them too. Can be added to or removed from an existing save; an existing save starts at the default 20.
description=Other mods that also speed up transfers stack with this one. With Faster Actions, for example, both speed-ups multiply.
description=
description=[h2]한국어[/h2]
description=아이템을 넣고 빼는 시간을 바닐라 시간 ÷ 샌드박스 옵션 값으로 바꿉니다. 기본값 20이면 20배 빠릅니다(0.1~100, 1은 바닐라).
description=멀티에서는 서버가 이동 시간을 정하고 클라이언트는 기다리기만 해서 Lua 모드로는 바꿀 수 없습니다. 이 모드는 서버의 시간 계산 자체를 Java로 고쳐서(ZombieBuddy) 한 개, 여러 개, 가방, 컨테이너, 차량, 바닥 모두 빨라집니다. 싱글에서도 같은 배수로 동작합니다.
description=무게, 가방이 찬 정도, 손재주 특성, 장갑은 바닐라대로 계산한 뒤 나눕니다.
description=필요한 것: [b]ZombieBuddy[/b] 모드, 스팀 실행 옵션 [b]-agentlib:zbNative --[/b] (속성 → 실행 옵션). 싱글에서 테스트했고 멀티는 테스트하지 않았습니다. 멀티에서는 서버(ZombieBuddy Java 에이전트 포함)와 모든 클라이언트에 ZombieBuddy와 이 모드가 필요합니다. Faster Actions 같은 다른 속도 모드와 같이 쓰면 효과가 곱해집니다.
