# Java: java/src/main/java/talkinghand/actionspeedmultiplier (Patches.java, Speed.java, LuaApi.java).
#
# Riskiest (break silently):
#  1. Actions: every timed action's time must keep going through ISBaseTimedAction:adjustMaxTime (create on the client, NetTimedAction.getDuration on the server)
#  2. Multiplayer transfers: the server must keep timing them with Transaction.getDuration; a new timing path would be vanilla speed again
#  3. Single-player transfers: ISInventoryTransferAction.new must keep setting maxTime and queueList[1].time; ISGrabItemAction.new must keep taking time as its third argument
#  4. Actions with their own clocks must keep naming them timePer*
#
# kind	target	note
